# 🍽 SmartBite AI

An AI-powered restaurant management and food ordering system built using Flask, PostgreSQL, HTML, CSS, and JavaScript.

## Features

- 🍕 Smart Menu
- 🤖 AI Food Recommendation Chatbot (Gemini)
- 🛒 Shopping Cart
- 💳 Checkout System
- 📦 Order Tracking
- 📍 Restaurant Locations
- 🔍 Search Food
- 🥗 Veg / Non-Veg Filter
- ⭐ Ratings
- ❤️ Wishlist UI
- 📱 Responsive Design

---

## Tech Stack

### Backend
- Flask
- PostgreSQL
- Gemini API

### Frontend
- HTML
- CSS
- JavaScript

### Database
- PostgreSQL

---

## Installation

```bash
git clone https://github.com/YOUR_USERNAME/SmartBite-AI.git

cd SmartBite-AI

python -m venv .venv

pip install -r requirements.txt

python app.py
```
